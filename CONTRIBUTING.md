# Contributing

Contributions that improve reproducibility, testing, documentation, or experimental design are welcome.

Before proposing a change:
1. Explain the research or engineering question.
2. Keep experiments reproducible with explicit seeds and configurations.
3. Report software versions and hardware where relevant.
4. Do not add performance claims without generated results and a clear protocol.
5. Run `python -m unittest discover -s tests -v`.

For substantial changes, include a short description of the expected effect and any limitations.
